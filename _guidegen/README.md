# Картинки для раздела «Инструкция»

Здесь генераторы скриншотов экранов для страницы «Инструкция» (вкладка в меню).

- `frags.html` — фрагменты реальных экранов платформы (с настоящим `styles.css`) и зелёные
  подписи «нажмите сюда».
- `shoot.py` — рендерит эти фрагменты через Playwright и кладёт PNG в `../guide-img/`.
  Эти PNG идут в продакшен, на них ссылается компонент `Guide` в `app.jsx`.

Перегенерировать картинки:

    python3 _guidegen/shoot.py

Самопроверка самой страницы (рендер настоящего `app.js` с мок-Supabase, без входа):

    python3 _guidegen/preview_shot.py

Если поправил тексты/вёрстку фрагментов, перегенери картинки и пересобери приложение
(`python3 build.py`).
