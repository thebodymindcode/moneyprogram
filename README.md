# Протокол денег

Статическое веб-приложение (React через CDN) с бэкендом на Supabase.
17-дневная программа: вход, прогресс по дням, задания с ответами, заметки, дневник.

## Запуск локально
Любой статический сервер из этой папки, например:

    python3 -m http.server 4317

Открыть http://127.0.0.1:4317/

## Публикация
Залито на GitHub Pages, сайт обслуживается из подпапки `/moneyprogram/`.
Все пути относительные, поэтому работает из подпапки.

## Настройки
- `config.js` — публичный ключ Supabase (безопасен на фронтенде, данные защищает RLS).
- `appConfig.js` — дата старта, час открытия дня, часовой пояс, тестовый режим.
- `supabase/schema.sql` — схема базы, права (RLS) и наполнение 17 дней.
- `supabase/storage_audio.sql` — приватный бакет `lesson-audio` для аудио уроков и права на него (грузит только админ, слушает только участник из списка). Запусти один раз после schema.sql.
